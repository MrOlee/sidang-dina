# Undangan Sidang — Andina Putri

Website undangan statis yang siap dijalankan dan di-deploy ke Vercel.

## Menjalankan secara lokal

Buka `index.html` langsung di browser, atau jalankan server statis apa pun dari folder ini.

## Foto dan musik

- Simpan foto utama dengan nama `foto.jpg` di folder proyek. Jika belum ada, website memakai foto cadangan dari URL yang sudah disediakan.
- Musik instrumental dibuat langsung di browser menggunakan Web Audio API dan mulai diputar setelah tombol **Buka Undangan** ditekan.
